## Fixed this session

- `6094c7d` — shotgun viewmodel: route to the hands' `Launcher` socket (matches
  `Shotgun.uc AttachBone="Launcher"`); for a non-grip root bone (`SG_Body`) apply an explicit
  tuned rotation+offset instead of the R_grip cancel. New `-bioshockshotgunrot` /
  `-bioshockshotgunoffset` capture flags.
- `4795435` — radial "SELECT WEAPON" prompt moved below the bottom segment label.

## Open gaps (not regressions — nothing here broke, it was never built)

1. **Runtime audio — entirely absent.** Biggest single gap for "1:1 with the game".
2. **AI pathfinding** — no NavMesh; straight-line fallback only.
3. **HUD liquid-fill material** (`M_Hud_LiquidFill`) renders invisible; flat tinted-mask fallback
   is forced by `bLiquidMaterialDisabled`. Bars don't have the liquid look.
4. **Weapon / plasmid icons** — no bitmaps in any SWF; radial + HUD show name-only.
5. **Shotgun hand grip** — gun placement fixed, but the `FidgetShotgun` clip poses the hands
   around where the gun *was* authored, not where it now sits. Proper fix: carry
   `MeshSocket.Transform` through the FBX manifest (see ENGINEERING_RULES §60).
6. **Status menu** — Map tab is a coords placeholder; Messages tab (audio diaries) not wired.
7. **Hacking** — pipe tiles are UMG shapes; Auto-Hack ignores inventory.
8. **Pause menu** — Options/Credits are stubs; a debug string is user-visible.
